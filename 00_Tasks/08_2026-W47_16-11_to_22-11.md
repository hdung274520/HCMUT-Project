### 6.1. Cognito và API (AWS)
1. [ ] `template.yaml`: thêm Cognito User Pool (tắt tự đăng ký), App Client cho web (không có secret, luồng authorization code + PKCE), domain đăng nhập của Cognito. Callback/logout URL: `https://hdung274520.github.io/HCMUT-Project/03_Code/04_web-app/` và `http://localhost:5500/` để thử
2. [ ] API Gateway: thêm Cognito authorizer. Các `GET` (`/sessions`, `/measurements`, `/vitals/daily`, `/vitals/latest`) dùng Cognito thay cho API key. Các `POST` của Pi **giữ** API key
3. [ ] CORS: `AllowOrigin` chỉ còn `https://hdung274520.github.io` (và localhost khi thử), `AllowHeaders` thêm `Authorization`. Lambda `respond()` trả đúng origin đó thay cho `*`
4. [ ] Deploy (`sam build && sam deploy`). Changeset không được **Delete** bảng nào
5. [ ] Tạo 1 người dùng bằng tay (Console hoặc `aws cognito-idp admin-create-user`)
6. [ ] Kiểm tra: `GET /vitals/latest` không token → 401; có token → 200. Pi vẫn `POST` được bằng API key (xem `upload.log`)

### 6.2. Web (`03_Code/04_web-app`)
1. [ ] `config.js` chỉ chứa giá trị **công khai** (URL API, domain Cognito, client id, URL trợ lý), không còn `API_KEY`. Từ giờ được commit lên GitHub; bỏ khỏi `.gitignore`

3. [ ] `api()` gửi header `Authorization: Bearer <id_token>` thay cho `x-api-key`. Token hết hạn hoặc API trả 401 thì về chế độ DEMO và hiện nút Đăng nhập
4. [ ] Chưa đăng nhập: giữ chế độ DEMO DATA như tuần 46
